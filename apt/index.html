cros3 APT Repository

This repository hosts Debian packages for cros3.

Repository Files

  • Public signing key
  • Release metadata
  • InRelease metadata

Install

curl -fsSL https://antoniofigueiredo.github.io/cros3/apt/repo-public-key.asc | sudo gpg --dearmor -o /usr/share/keyrings/cros3-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/cros3-archive-keyring.gpg] https://antoniofigueiredo.github.io/cros3/apt unstable main" | sudo tee /etc/apt/sources.list.d/cros3.list > /dev/null

sudo apt update
sudo apt install cros3-dkms
